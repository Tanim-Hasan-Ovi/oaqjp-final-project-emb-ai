# Final project

## AI-Based Web Application Development and Deployment

This project uses Python and IBM Watson NLP to develop an AI-powered emotion detection application. It analyses customer feedback and identifies five emotions: anger, disgust, fear, joy, and sadness.

### Technologies
- Python
- IBM Watson NLP
- Flask
- GitHub

### Objective
To detect emotions from customer feedback, identify the dominant emotion, and deploy the application using Flask.# Repository for final project
